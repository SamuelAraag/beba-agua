      Sair e apagar o token?

      O token some deste navegador e o GitHub não mostra ele de novo. Se você não tiver o token guardado, vai precisar gerar outro para entrar.

      Entrar no Beba Água

      O app grava direto no GitHub, na branch de dados do repositório dele. Gere um token só para isso:

      1. GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens.
      2. Generate new token, com acesso só ao repositório .
      3. Permissão Contents: Read and write.

      O token fica guardado só neste navegador.
